# БААЛЬБЕКСКАЯ ВЕРАНДА

Да, построить ВЕРАНДУ из камня или пирамиду МНОГО труднее чем коммитнуть

А ещё можно сплав доказательств, в частности синхронизацию коммитов с камнем

А ядерка и т.д. весь этот древний камень плавят в бесформенность

Надо вас принудить к миру и сделать сеточки `.moralfags` и всю нейтраль вроде `.i2p` `.onion` давить по многим параметрам и все центровые точки загонять в наиглубочайшее подполье вроде научной деятельности
